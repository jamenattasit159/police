# สคริปต์พากย์เสียง — คลิปสอนใช้งานระบบติดตามผู้ต้องหา ภ.จว.อ่างทอง

มี 2 คลิป: **คอมพิวเตอร์** (แนวนอน) และ **มือถือ** (แนวตั้ง)
ดูคลิปตัวอย่างแบบไม่มีเสียงพากย์ไปพร้อมกันตอนอัด ได้ที่ `video/tutorial/renders/` และ `video/tutorial-mobile/renders/`

## วิธีอัด (สำคัญ — ทำแบบนี้แล้วตัดคลิปได้ทันที)

1. **อัด 1 ไฟล์ต่อ 1 ฉาก** ตั้งชื่อไฟล์ตามรหัสฉากในตาราง เช่น `s05.m4a`, `m08.m4a` (รองรับ .m4a .mp3 .wav — อัดจากแอปบันทึกเสียงในมือถือได้เลย)
2. ไม่ต้องจับเวลาเป๊ะ พูดยาวกว่าเวลาในตารางได้ ระบบจะยืดฉากให้พอดีกับเสียงเอง (ถ้าพูดสั้นกว่า ฉากจะคงความยาวเดิม)
3. เว้นเงียบหัว-ท้ายไฟล์ไม่เกิน ½ วินาที
4. อัดในห้องเงียบ ถือมือถือห่างปากประมาณ 1 คืบ พูดช้ากว่าปกตินิดหน่อย
5. ส่งไฟล์มาทั้งหมด → ผมวางที่ `video/tutorial/assets/voice/` (คอม) และ `video/tutorial-mobile/assets/voice/` (มือถือ) แล้วเรนเดอร์ใหม่
   - ฉาก `intro` / `outro` ใช้ไฟล์เดียวกันทั้งสองคลิปได้

> ความหมายของสี แดง/ส้ม/เหลือง ยังไม่ได้กำหนด สคริปต์จึงพูดว่า "ตามที่ผู้บังคับบัญชากำหนด" — ถ้าได้ความหมายแล้ว แก้บท `s06` / `m06` ได้เลย

## เมื่อได้ไฟล์เสียงแล้ว (สำหรับคนตัดต่อ)

```bash
# วางไฟล์: video/tutorial/assets/voice/<รหัสฉาก>.m4a และ video/tutorial-mobile/assets/voice/<รหัสฉาก>.m4a
python video/build_tutorial.py
cd video/tutorial && npx hyperframes@0.9.6 render --docker -o "renders/วิธีลงข้อมูลผู้ต้องหา.mp4"
cd ../tutorial-mobile && npx hyperframes@0.9.6 render --docker -o "renders/วิธีลงข้อมูลผู้ต้องหา-มือถือ.mp4"
```
